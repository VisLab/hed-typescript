# hed-typescript API reference

This is the API reference for the `hed-validator` npm package, generated by TypeDoc from the hed-typescript
source. The guides, including installation and examples, are on the
[hed-typescript documentation site](https://www.hedtags.org/hed-typescript/).

The public API is exported from `src/index.ts`. Start with:

- `buildSchemasFromVersion` to load the HED schemas to validate against,
- `parseStandaloneString` and `parseHedString` to validate a single HED string,
- `BidsSidecar` and `BidsTsvFile` to validate BIDS sidecars and tabular files,
- `BidsDataset` to validate a whole BIDS dataset.
